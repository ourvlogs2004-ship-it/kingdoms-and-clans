# Kingdoms & Clans: Frontier

A more polished, mobile-friendly original browser strategy game prototype. Built with HTML, CSS, and JavaScript, with no external libraries or assets.

## Features
- Village with Town Hall, gold mines, elixir pumps, barracks, army camps, huts, cannons, archer towers, and walls
- Place, move, and upgrade buildings
- Resource production over time
- Train warriors and manage army capacity
- Enemy raid mode with troop deployment, target seeking, building damage, timer, stars, destruction %, and loot results
- Commander task rewards
- Local browser save
- Responsive touch controls and canvas-rendered cartoon art

## Run
Open `index.html` in a modern browser.

## GitHub Pages
Upload `index.html` to the root of a GitHub repository. Then go to **Settings → Pages → Deploy from a branch → main → /(root) → Save**.

## Limits
This is a local single-player prototype, not a commercial-scale Clash of Clans clone. It has no online multiplayer, accounts, server-side economy, matchmaking, or cloud save. It uses original code and emoji-based artwork.
