# Kingdoms & Clans (browser game)

A small, original, mobile-friendly village-building and raid strategy game prototype inspired by the broad genre of base-building strategy games.

## Run locally
Open `index.html` in a modern browser.

## Publish free with GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html` to the repository root (do not upload the ZIP itself).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, branch `main`, folder `/(root)`, then Save.
5. Open the URL GitHub Pages shows.

## Controls
- Tap **BUILD**, choose a building, then tap a clear area in the village.
- Tap a building to upgrade or move it.
- **ARMY** trains warriors for elixir.
- **ATTACK** starts a raid; tap inside the enemy base to deploy warriors.
- **SAVE** stores progress in this browser using localStorage.

## Notes
This is an original prototype, not a clone of Clash of Clans. It has no real online multiplayer, server-side accounts, or cloud saves. Game progress is local to the browser/device.
